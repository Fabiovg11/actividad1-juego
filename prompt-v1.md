# Prompt Versión 1

Rol: Actúa como desarrollador/a frontend que crea recursos accesibles para alumnado de 2.º DAW.

Tarea: Construye un juego web de preguntas llamado WebQuest: El Reto de la Cultura Web.

Contexto: Se ejecutará localmente al abrir index.html. El público es jóvenes de una asociación juvenil interesados en la tecnología y la cultura web.
Las preguntas son:
1. ¿En qué año se creó la primera página web de la historia? (Correcta: 1991)
2. ¿Qué significa la sigla CSS? (Correcta: Cascading Style Sheets)
3. ¿Qué lenguaje se ejecuta de forma nativa en el navegador para dar interactividad? (Correcta: JavaScript)
4. ¿Quién es considerado el padre de la World Wide Web? (Correcta: Tim Berners-Lee)
5. ¿Cuál de los siguientes es un elemento HTML5 semántico? (Correcta: <main>)
6. ¿Qué código de estado HTTP indica que un recurso no fue encontrado? (Correcta: 404)

Requisitos funcionales:
- Muestra una pregunta cada vez con cuatro respuestas.
- Indica si la respuesta es correcta y actualiza la puntuación.
- Al terminar, muestra la puntuación y un botón para reiniciar.

Requisitos de accesibilidad y calidad:
- Usa elementos HTML semánticos, etiquetas visibles y foco de teclado.
- No uses dependencias, imágenes remotas ni datos personales.
- Separa HTML, CSS y JavaScript.

Formato de salida:
1. Muestra primero el árbol de archivos.
2. Devuelve el contenido completo de index.html, styles.css y app.js en bloques separados.
3. Explica cómo probarlo localmente y enumera tres pruebas manuales.

Restricciones:
- No inventes características fuera de esta lista.
- No uses alert() para toda la interacción.
